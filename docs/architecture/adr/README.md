# RabbitMQ adapter architecture decisions

Architecture Decision Records (ADRs) preserve choices that affect the worker capability contract,
broker delivery semantics, lifecycle, security boundary, compatibility, and deployment model. User
guides describe how to operate the adapter; ADRs record why material design choices were selected.

No standalone ADRs have been recorded for this package yet. Add an ADR before merging a material
contract, delivery guarantee, security, dependency, or lifecycle change. Use the [ADR template](template.md).
